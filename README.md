# Autonomous Banking Resolution Agent

**Status:** Phase 1 Complete ✅  
**Build Time:** 4 weeks  
**Portfolio Impact:** High — Demonstrates agentic AI reasoning for AI PM interviews

## What This Is

A production-ready **12-step agentic reasoning system** for autonomous banking dispute resolution. Unlike chatbots that just generate text, this system creates investigation plans, selects tools dynamically, analyzes evidence against policies, calculates risk, and decides autonomously or escalates to humans.

## Quick Start

**Demo Mode (No API calls needed):**
```bash
python src/executor_demo.py
```

Expected output: All 12 steps complete in ~17 seconds.

**Live Mode (Gemini API):**
```bash
python src/executor_simple.py
```
